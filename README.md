# File Sorter

Автоматический сортировщик файлов для наведения порядка в папке загрузок. Скрипт отслеживает появление новых файлов и раскладывает их по соответствующим категориям (картинки, документы, видео и т.д.) на основе их расширения.

## Запуск

Для работы скрипта требуется библиотека `watchdog`.

```bash
pip install watchdog
python file_sorter.py
```

## Пример

Допустим, в папке `Downloads` появились файлы:
* `vacation.jpg`
* `report.pdf`
* `movie.mp4`

После работы скрипта структура изменится на:
* `Downloads/Images/vacation.jpg`
* `Downloads/Documents/report.pdf`
* `Downloads/Video/movie.mp4`

## Тесты

Если вы вносили изменения в логику сортировки, запустите тесты:

```bash
pytest -q
```
